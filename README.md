# Pacebar

ClaudeとCodexの5時間枠・週間枠の使用率を、Macのメニューバーに表示するアプリです。表示をクリックすると、リセットまでの時間や使用ペースも確認できます。

[ZIPをダウンロード](https://github.com/Pokare/pacebar/releases)

Appleシリコン搭載Mac、macOS 14以降に対応します。ZIPを解凍し、`Pacebar.app` を「アプリケーション」フォルダに移して開きます。

Claudeの使用率表示にはClaude Code、Codexの使用率表示にはCodexへのログインが必要です。Claudeの利用状況は、初回の同意後に、このMacのClaude Codeのログイン情報を使ってAnthropicへ問い合わせます。Claude側の仕様変更により、取得できなくなることがあります。

プレリリースです。Appleの公証を受けていないため、初回起動時にmacOSが警告を表示することがあります。
